# 📂 Projects

## 📊 1. Retail Sales & Customer Insights Dashboard

### Dashboard Features
- Total Sales KPI
- Total Customers
- Total Transactions
- Average Customer Age
- Sales by Product Category
- Transaction Trend Analysis
- Customer Distribution by Gender
- Quantity by Product Category
- Interactive Filters

### Key Insights
- Electronics and Clothing generated the highest sales.
- Customer distribution is nearly balanced between male and female customers.
- Daily transaction trends help identify peak business days.

## 📈 2. Superstore Sales Analysis Dashboard

### Dashboard Features
- Sales by Category
- Profit by Category
- Sales by State
- Regional Sales Summary
- Discount Analysis
- Profit Gauge

### Key Insights
- Technology is the highest-selling category.
- Sales vary significantly across states.
- Regional analysis highlights top-performing markets.

## 📉 3. Superstore Sales Performance Dashboard

### Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Average Discount
- Profit Margin
- Monthly Sales & Profit Trends
- Sales by Category
- Sales by Segment
- Quantity by Ship Mode
- Top 3 Profitable Products
- Interactive Month Filter

### Key Insights
- Monthly sales trends reveal seasonal variations.
- Consumer segment contributes the highest sales.
- Technology category generates the highest revenue.
