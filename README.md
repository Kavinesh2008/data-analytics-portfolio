## 📊 1. Retail Sales & Customer Insights Dashboard

An interactive Power BI dashboard designed to analyze retail sales performance and customer demographics.

### Dashboard Features

- Total Sales KPI
- Total Customers
- Total Transactions
- Average Customer Age
- Sales by Product Category
- Transaction Trend Analysis
- Customer Distribution by Gender
- Quantity by Product Category
- Interactive Filters

### Key Insights

- Electronics and Clothing generated the highest sales.
- Customer distribution is nearly balanced between male and female customers.
- Daily transaction trends help identify peak business days.
- Product category analysis helps identify high-performing products.

## 💊 4. MediVault Medicine Inventory Dashboard

A Power BI dashboard developed using a **500-record medicine inventory dataset** created for my MediVault Digital Medicine Inventory System.

The dashboard focuses on inventory monitoring, medicine stock levels, expiry tracking, and inventory value.

### Dashboard Features

- 💊 Total Medicines
- 💰 Total Inventory Value
- 🔴 Expired Items
- 🟠 Expiring Soon
- 📦 Stock Status Distribution
- 📊 Medicine Category Analysis
- 🏭 Supplier Analysis
- 📍 Storage Location Analysis
- 📅 Expiry Date Analysis
- 🔎 Interactive Dashboard Filters

### Key Metrics

The dashboard uses calculated measures and DAX to monitor:

- Total number of medicines
- Current stock quantity
- Inventory value
- Expired medicines
- Medicines expiring soon
- Low-stock medicines
- Out-of-stock medicines

### Key Insights

- Inventory levels can be monitored across different medicine categories.
- Low-stock medicines can be identified using minimum stock thresholds.
- Expired and soon-to-expire medicines can be monitored for better inventory management.
- Supplier and storage-location analysis helps understand inventory distribution.
- Inventory value provides an overview of the overall value of available stock.

### Dataset

The dashboard uses a **500-record synthetic medicine inventory dataset** containing information such as:

- Medicine ID
- Medicine Name
- Generic Name
- Category
- Dosage
- Manufacturer
- Batch Number
- Stock Quantity
- Minimum Stock
- Expiry Date
- Purchase Date
- Unit Price
- Supplier
- Storage Location
